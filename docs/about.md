# About pro-cron

## Who maintains it

pro-cron is built and maintained by [Mediusware](https://mediusware.com), a software company that designs and ships products for clients worldwide. The source lives at [github.com/mediuswareltd/pro-cron](https://github.com/mediuswareltd/pro-cron).

## Why it exists

A stripped-down crond clone in Go that reads a crontab, runs matching jobs each minute, and logs to stdout.

We publish these tools so teams can evaluate the real software, not a slide deck: clone it, run it, and read how it is put together.
