# Getting started

Install and run **pro-cron** locally.

## Prerequisites

- Working knowledge of Go
- Git and a terminal

## Install

```bash
go build -o pro-cron ./cmd/pro-cron
```

## Quick start

```bash
./pro-cron -f ./crontab
```
